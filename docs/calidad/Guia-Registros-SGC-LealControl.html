Guía rápida — Registros SGC en LealControl

Dónde encontrarlos y cómo probarlos

septiembre 2026

Orientación para el equipo de Calidad
  • Menú Calidad: Tablero SGC | Árbol documental | Registros operativos
  • Entrada general: Calidad → Registros operativos
  • Excel no es el maestro: el registro vive en el sistema; Excel solo sirve para exportar o como adjunto
PG01-R01

Lista de documentos

Cómo funciona
Se genera automáticamente desde el árbol documental del sistema. No se carga a mano: refleja los documentos vigentes cargados en el SGC.
Dónde verlo
Calidad → Registros → PG01-R01 (o /calidad/registros/pg01-r01). También desde Árbol documental.
Qué probar
Abrir la lista, verificar que aparecen documentos del árbol y exportar a Excel si está disponible.
PG01-R02

Lista de documentos externos

Cómo funciona
Lista generada de documentos de origen externo registrados en el sistema, alineada al control documental.
Dónde verlo
Calidad → Registros → PG01-R02 (o /calidad/registros/pg01-r02).
Qué probar
Abrir la lista, confirmar documentos externos visibles y exportar Excel si aplica.
PG03-R01

Seguimiento de quejas

Cómo funciona
Flujo estructurado de quejas: alta, seguimiento por estados y cierre. El registro vive en el sistema.
Dónde verlo
Calidad → Registros → Quejas (/calidad/registros/quejas).
Qué probar
Crear una queja de prueba, avanzar estados y generar/imprimir PDF.
PG04-R01

Programa de auditorías

Cómo funciona
Registro estructurado: el listado anual de auditorías constituye el programa. Incluye etapas de plan e informe.
Dónde verlo
Calidad → Registros → Auditorías (/calidad/registros/auditorias).
Qué probar
Crear una auditoría y completar etapas de plan e informe.
PG05-R01

Evaluación inicial de proveedores

Cómo funciona
Evaluación estructurada del proveedor antes de habilitarlo. Base para el listado de habilitados.
Dónde verlo
Calidad → Registros → Proveedores (pestaña R01).
Qué probar
Crear una evaluación inicial y guardar; revisar que quede asociada al proveedor.
PG05-R02

Listado de proveedores habilitados

Cómo funciona
Lista generada a partir de evaluaciones aprobadas. No es un Excel maestro: se deriva del sistema.
Dónde verlo
Calidad → Registros → Proveedores (pestaña R02).
Qué probar
Aprobar una evaluación y verificar que el proveedor aparezca en R02.
PG05-R03

Desempeño de proveedores

Cómo funciona
Seguimiento del desempeño de proveedores habilitados con criterios definidos en el módulo.
Dónde verlo
Calidad → Registros → Proveedores (pestaña R03).
Qué probar
Registrar o consultar una evaluación de desempeño y revisar el resultado.
PG06-R01

Capacitaciones

Consejos prácticos

  • Preferir el hub Calidad → Registros operativos para ubicar y probar cada registro.
  • También se puede abrir el documento padre en el Árbol documental y usar «Agregar registro».
  • Ayuda del módulo: Calidad → Ayuda.
  • Entorno de pruebas (staging): v2.lealcontrol.com.
